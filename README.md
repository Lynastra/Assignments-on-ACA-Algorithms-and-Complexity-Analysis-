# Assignments on ACA (Algorithms and Complexity Analysis)
Задания по курсу алгоритмы и анализ сложности. Каждое задание находится в отедельной папке. 
В readme каждого задания описано само задание и краткое пояснение, как задание выполнялось.
Список литературы для всех заданий примерно следующий: 
1) книга Кормана "Алгоритмы: построение и анализ", по 
которой в основном выполнялись задания (лучше для себя ничего не нашла, хотя разных книг перебрала много, начиная 
от книги Адитьи Бхаргавы "Грокаем алгоритмы" и заканчивая красной книгой Стивена Скиены 
"Алгоритмы. Руководство по разработке")
2) Лекции к курсу и лекции Андросова по курсу "Методы программирования"
(рандомизированная версия сортировки в частности взята оттуда).
