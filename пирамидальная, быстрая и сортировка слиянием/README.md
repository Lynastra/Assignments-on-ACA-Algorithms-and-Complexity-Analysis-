В данном задании требовалось реализовать три сортировки, основанные не на сравнениях:
1) Сортировку слиянием (Merge Sort)
2) Быструю сортировку (Quick Sort)
3) Пирамидальную сортировку (Heap Sort)

А затем провести бенчмарк (тестирование) данных алгоритмов на достаточно больших данных. По результатам тестов построить график зависимости скорости выполнения от размера входных данных.
Размеры входных данных были следующие: 50000, 100000, 500000, 1000000.
